# pfSense-Simple-Network-Suricata-Lab
Đây là dự án cá nhân xây dựng một lab cơ bản mô phỏng cách hoạt động của IPS/IDS trong hệ thống doanh nghiệp vừa và nhỏ được xây dựng hoàn toàn trên hệ thống ảo hóa (VMWare + GNS3)
English below:
This is a personal project to build a basic lab that simulates how an IPS/IDS operates in a small- to medium-sized enterprise (SME) environment. The entire lab is built using a virtualized infrastructure with VMware and GNS3.
